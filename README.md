## 🌟 أبرز المميزات (Features):

1. **📌 غرفة القيادة (Command Center HUD):**
   - مؤشرات لحظية للمهام والتكليفات القادمة ومعدل الـ GPA والـ Streak اليومي.
   - رادار المواعيد الحرجة (تسليمات الـ 48 ساعة القادمة).
   - خريطة نشاط برمجية (CS Contribution Heatmap) مستوحاة من GitHub.
   - اقتباسات برمجية يومية ملهمة لعمالقة علوم الحاسب.

2. **💻 إدارة المهام ومشاريع الكود (CS Tasks Hub):**
   - كانبان بورد (Kanban Board) متفاعل لتتبع دورة حياة الكود (Backlog, In Progress, Review, Done).
   - مصفوفة أيزنهاور (Eisenhower Matrix) لتصنيف الأولويات.
   - قائمة تفصيلية مع فلترة بالمواد والتقنيات (C++, Linux, Docker, Python, etc.).
   - خطوات فرعية لكل تكليف (Subtasks Checklist) مع شريط نسبة الإنجاز ومكافآت الـ XP عند الاكتمال!

3. **🎓 المركز الأكاديمي والكلية (Academic Hub):**
   - إدارة المقررات الدراسية (بيانات الدكتور، المعيد، السكاشن، مواعيد المحاضرات، وروابط درايف المادة).
   - محاكي الـ GPA التفاعلي (Interactive Semester GPA Simulator): غير التقديرات المتوقعة وشوف المعدل بيتغير لحظياً.
   - جدول ومواعيد امتحانات الميتيرم والعملي مع تغطية المنهج (Syllabus Checklist).

4. **🧠 متتبع مسائل البرمجة (LeetCode Tracker):**
   - تصنيف المسائل حسب الصعوبة (Easy, Medium, Hard).
   - توثيق الأنماط الخوارزمية (Two Pointers, Sliding Window, DP, Graphs, etc.).
   - تسجيل الـ Time & Space Complexity وفكرة الحل (Intuition).

5. **⏱️ منطقة التركيز العميق (Cyber Pomodoro & Audio Synthesizer):**
   - مؤقت بومودورو مع وضع الـ CS Deep Sprint (50 دقيقة).
   - **مولد صوت محيطي مدمج (Web Audio API Synthesizer)** يولد ترددات (40Hz Gamma Focus, Cyber Rain, Deep Space Drone) برمجياً ويعمل 100% أوفلاين بدون أي إنترنت!

6. **⌨️ موجه الأوامر التفاعلي (Hacker CLI Terminal):**
   - تيرمينال مدمج بضغطة `Ctrl + K` لتنفيذ الأوامر السريعة (`status`, `tasks`, `add`, `courses`, `leetcode`, `matrix`).

7. **📱 تطبيق قابل للتثبيت (Progressive Web App - PWA):**
   - يمكن تثبيته كتطبيق مستقل على سطح مكتب ويندوز / ماك أو الموبايل بدون شريط المتصفح!

---

## ⚡ الاختصارات السريعة (Keyboard Shortcuts):
- `Ctrl + K` أو `Ctrl + ~`: فتح الـ Hacker Terminal CLI
- `Ctrl + M`: إنشاء مهمة أو تكليف جديد فوراً
- `Esc`: إغلاق النوافذ المنبثقة
